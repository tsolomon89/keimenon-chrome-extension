# Project Context: Keimenon Lite

## Overview
Keimenon Lite is a Chrome extension that extracts user-authored messages from supported AI chat pages (ChatGPT + Claude) and allows users to copy them or export them.

## Tech Stack
- **Platform**: Chrome Extension (Manifest V3)
- **UI**: HTML, CSS (Vanilla with M3 Design Tokens), JavaScript (Vanilla)
- **Build Tool**: None (or minimal if needed, but prioritizing raw web technologies for an extension)

## Key Files
- `specs.md`: The detailed product specifications.
- `manifest.json`: Extension configuration.

## Development Principles
- **Privacy First**: Local-only, no storage of content, no telemetry.
- **Aesthetics**: Material Design 3 (M3) compliant.
- **Simplicity**: No complex build steps unless necessary.
